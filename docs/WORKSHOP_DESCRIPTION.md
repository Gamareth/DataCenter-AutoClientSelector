# Auto Client Selector

Auto Client Selector automatically selects the matching client after you save a
server IP address.

## Supported matching

- The IP belongs directly to one of the client's subnets.
- The IP belongs to a custom subnet with a direct route to one of the client's
  subnets.

The existing client is left unchanged when no client or multiple clients match.

## Important

- MelonLoader is required.
- The mod has no settings, buttons, or shortcuts.
- Provided as-is. Compatibility updates are not guaranteed.
- Co-op support is not claimed until it has been tested with two players.

Source code, releases, and issue reporting will be linked here before Workshop
publication.
